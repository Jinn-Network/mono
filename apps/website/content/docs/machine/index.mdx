Two surfaces are live today:

- [`/llms.txt`](/llms.txt) — the index of every docs page.
- [`/llms-full.txt`](/llms-full.txt) — every docs page concatenated.

Both are compiled from the same MDX tree these HTML pages are built from, so they cannot drift.

## Not yet

Pasteable onboarding prompts, an installable plugin, and an MCP server are designed but not yet shipped. The protocol document root moved to a dedicated origin, spec.jinn.network, which is not yet deployed.
