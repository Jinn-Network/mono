# revocation-v1

`example.json` is a sealed revocation companion record (§7.4b) generated by
`buildRevocationFixture` (`src/fixtures.ts`) and pinned as a static schema
golden. It validates with `validateRevocation` from `@jinn-network/trust-core`.

Revocation *authority* and *non-retroactivity* scenarios (valid signers,
unauthorized rejection, evidence-time ordering) are executable fixtures in
`src/conformance.ts`'s "revocation" battery, not static data -- they need
a matching resolved binding and are exercised through `verifyEnvelopeBinding`.
