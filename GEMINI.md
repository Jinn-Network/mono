# Gemini bootstrap

Edit skills only in [`.claude/skills/`](.claude/skills/). Gemini CLI discovers the generated [`.agents/skills/`](.agents/skills/) mirror.

Skill bodies use Claude Code tool names. Map them with [gemini-tools.md](https://github.com/obra/superpowers/blob/main/skills/using-superpowers/references/gemini-tools.md). Do not fork `SKILL.md` per tool.

See [`AGENTS.md`](AGENTS.md) for the Codex loading paths (`eng-day`, `implement-issue`) and [`CLAUDE.md`](CLAUDE.md) for repo conventions.
