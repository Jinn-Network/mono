# Rig

Reports in this repository are produced by the skills-bench rig in
[Jinn-Network/mono](https://github.com/Jinn-Network/mono) —
`client/scripts/skills-bench/` at the commit recorded in each report's run
manifest (`data/bench-manifest.json`). To re-run: pin that commit, then
follow `docs/runbooks/skills-bench.md` with the task set (or slate subset)
shipped next to the report's data — the report's own "Reproduce" section
gives the exact command.
