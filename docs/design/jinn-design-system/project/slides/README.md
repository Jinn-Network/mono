# Slides — Jinn technical-talk template

Six-slide template for technical talks. Dark-first, ink backgrounds, serif-italic for mood, mono for everything else.

## Slides

1. **Title** — full-bleed display, italic emphasis
2. **Section** — sigil + italic section title, darkest surface
3. **Content** — 4-column framework breakdown
4. **Quote** — oversized italic pull-quote with leather-accent word
5. **Data** — 4-up KPIs in a bordered grid
6. **Closing** — sigil + CTA

Edit `Slides.jsx` to add, reorder, or restyle. Each slide is ≤ ~70 lines and self-contained.
