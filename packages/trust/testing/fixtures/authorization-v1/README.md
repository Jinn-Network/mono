# authorization-v1

`example.json` is a sealed authorization Statement (§8.1) generated by
`buildAuthorizationFixture` (`src/fixtures.ts`) and pinned as a static
schema golden. It validates with `validateAuthorization` from
`@jinn-network/trust-core`.

Attenuation (exact-string subset checking, widening rejection) is Task
T15's adversarial-set scope, exercised via `checkAttenuation` in
`src/adversarial.test.ts`, not this directory.
