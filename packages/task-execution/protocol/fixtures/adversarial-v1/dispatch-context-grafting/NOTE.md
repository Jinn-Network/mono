Dispatch-context grafting into a re-sealed crate cannot be caught by structural validation alone: `grafted-dispatch-context.json` is a well-formed DispatchContext document (it passes `validateDispatchContext`), but its `attempt`/`nonce` were never genuinely conveyed to an executor at dispatch time. Per §24/§18, this must be caught by the `dispatch-binding` verification check (Layer 3: binding integration, out of this milestone's scope), which compares the crate's captured dispatch-context input against the backend's own dispatch record — not by protocol-layer structure alone.
