# `@jinn-network/benchmarking-evidence`

Application-neutral verification and deterministic assembly for evidence-native
benchmarking. It resolves exact Evidence Protocol records referenced by an
Evidence Cohort, checks their Task and Result bindings, and assembles or replays
Matrix v2 using assembly procedure 3.0.

The package has no Task Execution Protocol dependency. Submission, Attempt, and
Delivery records are optional commissioning provenance outside this package.
