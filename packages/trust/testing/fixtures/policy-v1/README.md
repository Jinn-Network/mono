# policy-v1

`example.json` is a sealed trust-policy document (§9) generated by
`buildPolicyFixture` (`src/fixtures.ts`) and pinned as a static schema
golden. It validates with `validateTrustPolicy` from `@jinn-network/trust-core`.

Policy-*chain* verification (dual-threshold signer sets, anti-rollback,
`refreshBy` freshness, competing genesis) is `@jinn-network/trust-core`'s
own scope (Task T7, `policy.test.ts`, `fixtures/policy-chain-v1/`) -- this
directory carries only the single-document schema golden.
