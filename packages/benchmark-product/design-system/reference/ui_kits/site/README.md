# UI kit — Marketing site

Cold-visitor surface. The five-second read is the H1: *Compare agents on the same work.* The deeper
promise arrives in the sub: publish a claim people can check.

**Files**
- `index.html` — the landing page (nav scrolls between sections; the report index links to the report kit)
- `Site.jsx` — header, hero, pillars, agent-native section, report index, footer
- `kit-icons.jsx` — Lucide wrapper + mark

**Rules this kit encodes**
- The hero proves rather than asserts: a real method lock, a real accounting bar and a real assurance
  meter sit beside the headline, not a decorative product shot.
- The one dark section on the site is the agent-native block. Dark is a device for the machine-facing
  story, not the default mode.
- "Built on Jinn." appears once, in the footer's legal line, at the smallest type size on the page.
- No shields, seals, checkmarks or logo walls.
