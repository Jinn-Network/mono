title: Machine surfaces
description: What an agent reads instead of these pages.
---

- [`/llms.txt`](/llms.txt): the index of every docs page.
- [`/llms-full.txt`](/llms-full.txt): every docs page concatenated.

Both are compiled from the same MDX tree these HTML pages are built from, so they cannot drift.

The protocol's own machine-readable documents (schemas, profiles and conformance vectors) are not served by this site. They are in [Jinn-Network/spec](https://github.com/Jinn-Network/spec).
