# Network Explorer SPA Implementation Plan (ebu7.4)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or executing-plans. Implementer subagents building UI: also invoke `frontend-design:frontend-design` and follow `DESIGN.md`/`BRAND.md`. Steps use `- [ ]`.

**Goal:** The public, daemon-free **network explorer SPA** — Network + Per-SolverNet views, the Learning panel (resolved-rate headline + learning-curve chart + checkpoint timeline), the quality-first faceted leaderboard (with the train/frozen split), an Operator detail view, all reading the indexer's `/explorer/*` JSON routes (and Ponder GraphQL where useful), with URL-state-as-source-of-truth permalinks — built per `DESIGN.md`/`BRAND.md` on the explorer UI kit. Replaces the `ebu7.5` placeholder page; served by the indexer at `/`. This is the `rdod` deliverable: deployed with the SolverNet filter pinned to SWE-rebench v2 it satisfies `jinn-mono-rdod`'s acceptance criteria.

**Architecture:** A React 18 + Vite 5 + TypeScript SPA living at `packages/indexer/explorer/` (its own `package.json`/`vite.config.ts`/`tsconfig.json` — mirrors `client/src/dashboard/spa/`). Vite builds to `packages/indexer/public/`. The indexer (`packages/indexer/src/api/index.ts`) serves `public/` statically at `/` (SPA fallback to `index.html`) instead of the inline `c.html(PLACEHOLDER_HTML)` route — needs a static-serve middleware dep. The indexer's `package.json` `build` script also builds the explorer. Data layer: `@tanstack/react-query` (already a repo dep) over typed `fetch` to `/explorer/*` (in dev, Vite proxies `/explorer` and `/graphql` to `http://127.0.0.1:42069`); a small poller (refetchInterval) for freshness. Routing: `wouter` (already a repo dep) with the URL query string as the source of truth for scope/facets/sort/window/open-detail (every view a permalink; back/forward works). Visuals: import `colors_and_type.css` + `foundations.css` from `docs/design/jinn-design-system/project/` (copied into `explorer/src/styles/`), use the CSS variables directly (no Tailwind — matches the UI kit's inline-style-with-`var(--…)` approach and follows `DESIGN.md` literally). Charts: `uplot` (~50KB) for the time-series (learning curve, activity-over-time); hand-rolled SVG for bars / scatter / the checkpoint timeline / composition (no heavy chart lib). No emoji, no gradients, hairline borders, linear motion, `tabular-nums` everywhere, `prefers-reduced-motion` honored.

**Tech stack:** React 18, Vite 5, TypeScript 5, `@tanstack/react-query` 5, `wouter` 3, `uplot` (new dep — in the `explorer/` sub-package only), `clsx` (already used in the repo SPA). `vitest` + `@testing-library/react` for component tests (mirror the operator SPA's test setup).

**Reference:** design `docs/superpowers/specs/2026-05-12-network-explorer-design.md` (§2 view scopes, §5 Learning panel, §6 dimensions/leaderboard, §7 visual + frontend impl — read all of §7); `BRAND.md` (voice, lexicon, headless posture), `DESIGN.md` + `DESIGN.json` (visual tokens); UI kit `docs/design/jinn-design-system/project/ui_kits/explorer/` (`Chrome.jsx` — Logo/TopNav/SearchBox/StatusBar; `Data.jsx` — StatusChip/KPI/KPIRow/WishRow/TableHead; `WishDetail.jsx` — right-pane master-detail; `index.html` — the assembled reference page; `README.md`); existing SPA `client/src/dashboard/spa/` (`package.json`/`vite.config.ts`/`tsconfig.json`/`postcss.config.cjs` — the build pattern to mirror, minus Tailwind); the `/explorer/*` route response shapes — read `packages/indexer/src/api/explorer.ts` for the exact JSON each route returns (network: tasksPosted/tasksSettled/tasksRefunded/attempts/distinctOperators/solverNetsRunning/verdicts/verdictsPass/resolvedRate/jinnDistributedOperator/jinnDistributedDao/mostRecentSettlementBlock/composition{byMode,byHarness}/enrichmentCoverage + freshness; solvernets: {solvernets:[{cid,status,launcherAgentId,statusUpdatedAt,tasksPosted,tasksSettled,attempts,verdicts,verdictsPass,resolvedRate}]} + freshness; solvernet/:cid: that + learningCurveBuckets/learningCurveRolling/trainBoard{ranked,lowVolume}/frozenBoard/checkpointTimeline{checkpoints,note}/freezeIntegrity{violations,verifiedFrozenShare,frozenAttempts}; operators: {ranked:[{...,rank,dominantMode,dominantHarness}],lowVolume,minVerdicts,appliedFilters?,meta{jinnAttribution}} + freshness; operator/:addr: {operator,dominantMode,dominantHarness,dominantSolverType,perSolverNet:[{cid,status,attempts,settledContribution,verdictsTotal,verdictsPass,resolvedRate,modeBreakdown}],totals,meta} + freshness).
